# HOW TO INSTALL (Linux)

1. Prefer installing from the git repo (no zip needed):

   cd ~
   git clone https://github.com/TectiveJK/drone-flight-test-reporter-web.git
   cd drone-flight-test-reporter-web
   git pull
   chmod +x scripts/install-desktop.sh
   ./scripts/install-desktop.sh

2. After install, start the app with either:
   - the Desktop shortcut "Drone Flight Test Reporter"
   - or:

   ~/.local/bin/drone-flight-test-reporter

3. If no shortcut appears, look in:
   - ~/Desktop
   - ~/Bureaublad   (Dutch Ubuntu)
   - ~/.local/share/applications/
