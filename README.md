# Drone Flight Test Reporter — Public Web Version

Browser-based public version of Drone Flight Test Reporter.

## Features

- Multi-flight reports
- UAV / aircraft category and model
- Car / Van plate selection
- Test Objective Type selection
- Equipment / Hardware entry
- JSON report save/open
- Markdown export
- Print / PDF export
- Responsive desktop and mobile UI
- Voice notes where supported by the browser

This repository is intentionally separate from the Linux/Electron and iOS/PWA versions.
